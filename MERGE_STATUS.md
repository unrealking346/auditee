# Waeve Canonical Merge

This is the canonical Waeve project assembled from the preserved Waeve
source variants in `_sources/`.

## Principle

All source variants remain preserved and are not modified.

Implementations are being reconciled into one production-oriented Waeve
ecosystem rather than blindly overwriting duplicate files.
